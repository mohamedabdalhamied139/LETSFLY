1. Raccourcis des tables de jeu :
• P : Annoncer la liste et le nombre de joueurs présents à la table.
• T : Annoncez le nom du joueur dont c'est actuellement le tour.
• R : Annoncez les cartes actuellement sur la table.
• Maj + R : annoncez le mode de jeu Scopa, les règles actives et le score cible.
• C : Annoncez le nombre de cartes que vous avez capturées et celles restantes en banque.
• H : Annoncez le nombre de cartes que vous avez en main.
• S : Annoncez le total actuel des points et l'objectif de chaque équipe ou joueur.
2. Raccourcis de lecture et de navigation :
• Flèches haut et bas : naviguez entre vos cartes en main pour entendre le nom et la couleur de chaque carte.
• Enter : démarrez la partie en restant concentré sur la table ou jouez la carte sélectionnée pendant la partie.
• Échapper : fermez le menu de sélection de captures multiples et revenez à la main.
3. Raccourcis de gestion du jeu (pour l'hôte de la salle) :
• Entrée : démarrez le jeu lorsque vous vous concentrez sur l'élément de table.
• Maj + X : Terminez la partie en cours.
• B : Ajoutez un joueur robot (bot) à la salle.
• Maj + B : supprime le dernier bot ajouté.
4. Raccourcis d'aide générale :
• F1 : ouvre le menu de raccourcis rapides.
• Ctrl + F1 : ouvre les règles complètes du jeu et son explication.
