1. Game Table Shortcuts:
• P: Announce the list and number of players present at the table.
• T: Announce the name of the player whose turn it currently is.
• R: Announce the cards currently on the table.
• Shift + R: Announce the Scopa game mode, active rules, and target score.
• C: Announce the number of cards you captured and the remaining in the bank.
• H: Announce the number of cards in your hand.
• S: Announce the current total points and the target for each team or player.
2. Playing and Navigation Shortcuts:
• Up and Down Arrows: Navigate between your hand cards to hear the name and suit of each card.
• Enter: Start the game while focused on the table, or play the selected card during play.
• Escape: Close the multiple capture selection menu and return to the hand.
3. Game Management Shortcuts (for the Room Host):
• Enter: Start the game when focused on the table element.
• Shift + X: End the current game.
• B: Add a robot (bot) player to the room.
• Shift + B: Remove the last added bot.
4. General Help Shortcuts:
• F1: Open the quick shortcuts menu.
• Ctrl + F1: Open the full game rules and explanation.
