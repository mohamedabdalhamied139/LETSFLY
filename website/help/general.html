TableVerse — شرح اللعبة الحالية

شرح اللعبة الخاصة بالطاولة الحالية لم تتم إضافته بعد.

استخدم F1 لعرض اختصارات اللعبة المتاحة.

استخدم Ctrl+F1 لفتح شرح اللعبة الكامل بعد إضافة ملف قواعدها.

TableVerse — دليل الاختصارات العامة المشتركة

أولاً: اختصارات المساعدة والمعلومات العامة

  • F1: فتح نافذة استعراض الاختصارات.
  • Ctrl+F1: فتح شرح وقواعد اللعبة (أو قائمة الألعاب عند الضغط في الشاشة الرئيسية).
  • F2: نطق رصيد العملات والمحفظة.
  • F3: فحص سرعة الاتصال بالخادم (Ping).
  • F4: التبديل بين وضع اللعب ووضع المشاهدة (Spectator).
  • F5: إعادة الاتصال اليدوي بالخادم عند انقطاع الاتصال.
  • Shift+T: نطق وقت الطاولة المنقضي منذ بدء اللعب.

ثانياً: اختصارات الاستعلام عن الطاولة واللاعبين

  • P: نطق قائمة وعدد اللاعبين المتواجدين على الطاولة.
  • Shift+P أو Shift+ح: فتح قائمة اللاعبين التفاعلية على الطاولة (لإجراء تفاعلات معهم).
  • T: نطق اسم اللاعب صاحب الدور الحالي.
  • S: نطق النتيجة الحالية أو مجموع النقاط والهدف.
  • R: نطق الكارت أو النرد أو القطعة الملعوبة حالياً على الطاولة.
  • Shift+R أو Shift+ق: نطق القواعد والإعدادات المفعلة للطاولة الحالية.
  • C: نطق معلومات إضافية سريعة (مثل رصيد الجولة، كروت البنك المتبقية، أو كشف مخالفة).
  • V: نطق عدد الكروت المتبقية في يد اللاعبين أو استعراض قطع اللوحة.

ثالثاً: اختصارات إدارة الطاولة (لصاحب الغرفة / المضيف)

  • Enter: بدء اللعبة عند الوقوف على عنصر الطاولة في غرفة الانتظار.
  • Shift+X: إيقاف وإنهاء اللعبة الحالية والعودة لغرفة الانتظار.
  • B: إضافة لاعب روبوت (بوت) إلى الطاولة.
  • Shift+B: طرد أو إزالة آخر بوت تمت إضافته.
  • Ctrl+H: تبديل خصوصية الطاولة بين عامة وخاصة.

رابعاً: اختصارات المحادثة والصوت

  • M: كتم أو إلغاء كتم الميكروفون في المحادثة الصوتية.
  • Alt+Shift+V: تشغيل أو إيقاف المحادثة الصوتية للطاولة.

خامساً: اختصارات القوائم والتنقل العامة

  • Ctrl+F: فتح قائمة الأصدقاء.
  • Ctrl+W: فتح قائمة المتواجدين الآن على المنصة.
  • Apps أو Shift+F10: فتح قائمة السياق / الخيارات.
  • Q: الخروج من الطاولة أو الغرفة بعد تأكيد الخروج.
  • Escape: إغلاق النوافذ والقوائم السريعة والرجوع.

ملاحظة:

لكل لعبة اختصارات خاصة إضافية باللعب (مثل مفاتيح الأسهم، Enter للعب، وSpace للسحب أو تنفيذ الضربات)، يمكنك دائماً الضغط على F1 داخل أي طاولة لمعرفة الاختصارات الخاصة بها بالتفصيل.

TableVerse — General Common Shortcuts Guide

1. Help & System Shortcuts:

  • F1: Open shortcuts viewer window.
  • Ctrl+F1: Open game rules viewer (or games list on main screen).
  • F2: Announce coins and wallet balance.
  • F3: Check connection ping to server.
  • F4: Toggle between player mode and spectator mode.
  • F5: Reconnect manually to server.
  • Shift+T: Announce elapsed table play time.

2. Table & Player Query Shortcuts:

  • P: Announce players list and count on table.
  • Shift+P: Open interactive table players list.
  • T: Announce player whose turn it is.
  • S: Announce current score, round points, or target score.
  • R: Announce current top played card, dice, or domino board ends.
  • Shift+R: Announce room rules and active table settings.
  • C: Announce quick game context (round score, remaining bank, etc.).
  • V: Announce remaining cards count in players hands or board tiles.

3. Table Host & Management Shortcuts:

  • Enter: Start game when focused on table item in waiting room.
  • Shift+X: Terminate current game and return to waiting room.
  • B: Add robot bot player to room.
  • Shift+B: Remove last added bot player.
  • Ctrl+H: Toggle table privacy between public and private.

4. Voice & Chat Shortcuts:

  • M: Mute or unmute microphone in voice chat.
  • Alt+Shift+V: Toggle room voice chat on or off.

5. General Navigation & Menus:

  • Ctrl+F: Open friends list.
  • Ctrl+W: Open online users list.
  • Apps or Shift+F10: Open context menu.
  • Q: Leave table or room after confirmation.
  • Escape: Close popup dialogs and menus.

Note:

Each game has additional gameplay shortcuts (such as Arrow keys, Enter to play, and Space to draw or hit), press F1 inside any table to view its full game-specific shortcuts.

TableVerse — Guide général des raccourcis courants

1. Aide et raccourcis système :

  • F1 : ouvre la fenêtre de visualisation des raccourcis.
  • Ctrl+F1 : Ouvrir la visionneuse des règles du jeu (ou la liste des jeux sur l'écran principal).
  • F2 : Annoncer les pièces et le solde du portefeuille.
  • F3 : Vérifiez le ping de connexion au serveur.
  • F4 : Basculer entre le mode joueur et le mode spectateur.
  • F5 : Reconnectez-vous manuellement au serveur.
  • Maj+T : annonce le temps de jeu écoulé sur la table.

2. Raccourcis de requête de table et de lecteur :

  • P : Annoncer la liste des joueurs et compter sur la table.
  • Shift+P : Ouvrir la liste des joueurs de la table interactive.
  • T : Annoncer le joueur dont c'est le tour.
  • S : Annoncer le score actuel, les points arrondis ou le score cible.
  • R : Annoncer la fin des cartes, des dés ou des dominos actuellement les plus joués.
  • Maj+R : Annoncer les règles de la salle et les paramètres actifs de la table.
  • C : Annoncer le contexte de jeu rapide (score du tour, banque restante, etc.).
  • V : Annoncez le nombre de cartes restantes dans les mains des joueurs ou dans les tuiles du plateau.

3. Raccourcis d'hôte et de gestion de table :

  • Entrée : démarrez le jeu lorsque vous vous concentrez sur un élément de table dans la salle d'attente.
  • Maj+X : Terminez la partie en cours et retournez dans la salle d'attente.
  • B : Ajoutez un joueur robot à la pièce.
  • Maj+B : Supprime le dernier joueur bot ajouté.
  • Ctrl+H : basculer la confidentialité des tables entre public et privé.

4. Raccourcis voix et chat :

  • M : désactiver ou réactiver le microphone dans le chat vocal.
  • Alt+Maj+V : activer ou désactiver le chat vocal dans la salle.

5. Navigation générale et menus :

  • Ctrl+F : ouvrir la liste d'amis.
  • Ctrl+W : Ouvrir la liste des utilisateurs en ligne.
  • Applications ou Maj+F10 : ouvrir le menu contextuel.
  • Q : Quittez la table ou la salle après confirmation.
  • Échapper : Fermez les boîtes de dialogue et les menus contextuels.

Remarque :

Chaque jeu dispose de raccourcis de jeu supplémentaires (tels que les touches fléchées, Entrée pour jouer et Espace pour dessiner ou frapper), appuyez sur F1 dans n'importe quel tableau pour afficher tous les raccourcis spécifiques au jeu.
